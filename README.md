# DTB Vault — arquivos aprovados

Cópia semanal automática dos arquivos aprovados no DTB Vault, organizados por
`Console-Revisão da placa/`. Cada pasta tem um `index.json` com SHA-256,
SoC, RAM e a origem de cada arquivo. Não edite este repositório à mão: o
próximo backup sobrescreve as alterações.
